# E-commerce Sales Analysis Dashboard

> 🚧 **Work in progress** — this project is currently being built.

## Overview
An end-to-end analysis of real sales data from an e-commerce business that sold digital gaming products in Egypt. The data has been **anonymized**: all customer names, contact details, and account information were removed before analysis.

## Goals
- Analyze **monthly revenue** and sales trends
- Identify **best-selling products**
- Measure **repeat-customer** behavior and retention
- Build an **interactive Power BI dashboard** to present the findings

## Tools
- **Excel** – data cleaning and anonymization
- **SQL** – data analysis
- **Power BI** – dashboard and visualization

## Project Structure (planned)
```
data/        anonymized dataset
sql/         analysis queries
dashboard/   Power BI file (.pbix) and screenshots
```
